This is a temporary article for testing the MDX writing layout. It is not a published essay, but it gives the article page enough texture to inspect while the real notebook is still empty.

## Why this fixture exists

A writing page needs to handle more than a title and a paragraph. This fixture checks:

- readable paragraphs and vertical rhythm
- headings and nested sections
- inline `code` and external links
- quotations and fenced code blocks

> Good tools should make careful thinking easier, not make the thinking disappear.

## A small example

Here is a deliberately simple function. The code block should scroll horizontally on narrow screens without pushing the page wider than the viewport.

Inline math such as $a^2 + b^2 = c^2$ should sit naturally in a sentence.

$$
f(x) = \int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi}
$$

```ts
export function describeNote(title: string, published: boolean) {
  return published ? `${title} is live` : `${title} is still a draft`;
}

console.log(describeNote("A small note", false));
```
